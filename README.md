# spades-tracker

A self-contained spades score tracker — a single static `index.html` (HTML + CSS + JS, no build step, no dependencies).

**Live:** https://spades-tracker.vercel.app

## Edit & preview

Just open `index.html` in a browser, or serve the folder:

```powershell
# any static server works, e.g.
npx serve .
```

## Deploy

Deployed on Vercel (project `spades-tracker`). To publish changes:

```powershell
vercel deploy --prod
```

The repo is also linked to Vercel, so if you connect it on GitHub, pushes to `main` will deploy automatically.
